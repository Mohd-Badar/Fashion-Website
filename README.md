# 👕 BADAR STUDIO - Fashion Website

A modern fashion e-commerce website built using HTML, CSS, and JavaScript.

---

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript
- LocalStorage

---

## Features
- Responsive design
- Product listing section
- Product details page
- Shopping cart system
- Customer reviews section
- New arrivals section
- Add to cart functionality
- Cart count update using JavaScript
